# Outlook Setup Notes

## Purpose

Use Outlook for stakeholder communication, release advice requests, Go/No-Go updates, TeK handover mails, and release announcements.

## Current Working Mode

- Draft mail content from the local templates and stakeholder references.
- Open Outlook when possible for final review and sending.
- For release advice mails, always open the generated `.eml` draft in Outlook with the release-items PDFs attached, unless Wouter explicitly asks not to.
- If Outlook automation is not available, provide a ready-to-send mail with To, CC, subject, and body.

## Future Connector/MCP Notes

When an Outlook connector or MCP is configured, keep credentials outside this workspace. The workflow should:

- Create a draft, not send automatically, unless explicitly requested.
- Fill To/CC based on the LMS stakeholder list.
- Keep missing release values as visible placeholders.
- Preserve final manual review by Wouter for external stakeholder mails.
