# Figma Setup Notes

## Purpose

Use Figma for design references linked from user stories and feature discussions.

## Working Rules

- Store Figma links in `figma/links.md`.
- In user stories, include the exact Figma link or write `TBD` if no design exists.
- Do not copy private design assets into this workspace unless needed and allowed.

## Future Connector/MCP Notes

When a Figma connector is configured, use it to inspect frames, components, and screenshots for story writing and acceptance criteria. Keep tokens outside this workspace.
