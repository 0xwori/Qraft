# LMS Procedures

This folder contains procedures that Codex must follow for repeated LMS work.

Use these files when the request matches the procedure. The procedure is part of the task, not optional background.

## Available Procedures

- `release-advice-mail.md`: prepare a release advice mail, create the release-items PDFs, attach them to the draft, and open the draft in Outlook for review.

## Rules

- Follow the matching procedure before giving the final answer.
- Keep missing values visible as placeholders. Do not invent build numbers, Jira links, ticket IDs, or dates.
- Do not send mail externally unless Wouter explicitly confirms sending.
