This deck uses the **block-frame** theme (namespace: `BlockFrame`).

- All slides MUST use `BlockFrame.<Variant>` components.
- Preserve the neobrutalist visual system: 4px black borders, hard shadows, square corners, pastel-neon blocks, Inter display type, and Space Grotesk labels.

1. Cover: Bitcoin as a digital scarcity network.
2. Timeline: keys, nodes, mining, blocks.
3. Stats: 21M supply, approximate block timing, halving interval, open verification.
4. Features: supply, settlement, custody trade-offs.
5. End: infrastructure rather than ticker.
