# Outlook Monitoring Subproject

Purpose: prepare and later run safe Outlook monitoring for q-Tapwise through Microsoft Graph.

Current status: setup notes only. No live mailbox monitoring is running.

Rules:

- Whole-inbox access is allowed after setup.
- Store only short summaries and action items.
- Do not store raw email bodies.
- Do not store personal data or secrets.
- Do not send, delete, move, or edit emails without explicit approval.
