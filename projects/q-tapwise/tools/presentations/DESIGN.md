# q-Tapwise Presentation Design Context

Use this file for q-Tapwise slide design guidance.

Do not store secrets here.

## Style

Slides should follow the local `../../design.md` guide:

- warm cream or stone background
- Tapwise orange accent
- Geist Sans style typography
- clear education-first message
- practical and calm layout
- no generic AI-demo visuals

## Best Uses

Use decks for:

- GTM plans
- student/parent positioning
- social media calendars
- ad campaign concepts
- investor or partner storytelling

## Slide Rules

- One main idea per slide.
- Use simple headings.
- Keep text short.
- Use orange only for emphasis, CTA, or key numbers.
- Prefer real product examples, workflow mockups, or clear diagrams over decorative graphics.
