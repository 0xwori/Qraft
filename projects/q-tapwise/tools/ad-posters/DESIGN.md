Ads must look like Tapwise, not like a separate generic AI ad system.

## Visual Direction

- Use a warm stone canvas close to `#faf8f6`.
- Use Tapwise orange `#fd6521` only for the strongest accent: CTA, active highlight, or small badge.
- Use Geist Sans for all ad typography.
- Use dark ink text close to `#1c1c22` and muted text close to `#6b6b7a`.
- Use soft white or white/80 cards with fine borders close to `#e8e8ec`.
- Use rounded cards and shells, usually 24px to 36px for landing-style ad visuals.
- Use subtle shadows only, never dramatic depth.
- Use low-opacity radial color only as atmosphere, not as separate decorative blobs.
- Keep the message education-first: learning, exam prep, own material, confidence, and saving time.
- Use one main CTA.
- Keep all text readable in every export size, especially 320x50, 300x250, and 160x600.
- Make motion feel like a product demo: fade, lift, reveal, scrub. No bounce, no flashy effects.

## Default Creative Structure

Most q-Tapwise ads should start from this structure:

- Tapwise brand row with small mark and optional Beta badge.
- Short audience or benefit badge.
- One clear headline.
- One short supporting sentence.
- One CTA.
- Real Tapwise logo asset when available.
- Visual product evidence for larger sizes: screenshot, generated/edited study visual, illustration, or icon-led workflow.
- Optional simple product/workflow mockup for larger sizes.

For small banners, remove the mockup and keep brand, headline, and CTA only.

## Preview And Export Rule

- Always preview the ad in the browser before exporting.
- Do not export a revised ad until Wouter has seen the preview or explicitly asks to export.
- The preview UI can edit and save `campaign.tsx`; use it for quick JSX edits.
- Run an Impeccable-style check before final export: brand match, visual hierarchy, text fit, visual asset use, CTA clarity, and no generic AI-demo feel.

## Avoid

- generic AI hype
- crowded text
- cold enterprise-blue styling
- neon gradients
- overdecorated visuals
- random colors outside the Tapwise palette
- pure white full-page backgrounds
- gradient buttons or gradient cards
- too many orange elements at once
- tiny disclaimers that cannot be read
