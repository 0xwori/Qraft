# q-Tapwise MCP And Connector Notes

Store MCP setup notes and connector templates here.

Use environment variable names for secrets. Never store real secrets in this folder.

## Planned Connectors

- Microsoft Graph for Outlook mail monitoring.
- LinkedIn for post drafting and future publishing.
- Meta for Facebook, Instagram, and ads planning.

## Current Status

This project only contains setup notes right now. No live Outlook, LinkedIn, Meta, Instagram, Facebook, or Ads connector has been confirmed yet.

## Safety Rule

Any connector that can read a private inbox, publish social posts, change ads, or spend money must be used only after Wouter explicitly approves the action.
