# Skill: Manual Ad Upload Pack

Use this skill when Wouter wants to manually upload exported ad files to Meta, Instagram, Facebook, LinkedIn, or another ad platform.

## Role

Prepare a simple upload checklist and copy pack.

This skill does not publish ads and does not call ad platform APIs.

## Checklist

For each exported creative, provide:

- file path
- size
- placement suggestion
- primary text
- headline
- CTA
- audience note
- manual review note

## Safety Rules

- Do not spend money.
- Do not launch campaigns.
- Do not change budgets.
- Do not call Meta, Facebook, Instagram, or LinkedIn APIs.
- Ask Wouter for explicit approval before any future live posting tool is used.

## Output Format

```markdown
# Manual Upload Pack

## Files

- [file] - [size] - [placement]

## Copy

Primary text:
Headline:
CTA:

## Audience

[Audience]

## Manual Checks

- Preview looks correct.
- Text is readable.
- CTA is correct.
- Budget and audience are approved before launch.
```
